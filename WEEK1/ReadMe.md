# WEEK 1 - Basics of JavaScript

## Overview
This week focuses on the fundamentals of JavaScript through small console-based programs. The exercises practice conditional statements, loops, array traversal, searching, aggregation, and simple object manipulation.

## Files

### Biggest_of_2Numbers.js
Compares two hardcoded numbers using `if/else` and prints which one is larger.

### Biggest_of_3Numbers.js
Compares three hardcoded numbers and prints the biggest value using chained `if/else if/else` checks.

### FindingBigAmong_3numbers(arr).js
Defines a function that scans an array and returns the largest number.

### FIndingSmallAmongArr.js
Finds the smallest value in an array by iterating through all values and tracking the minimum.

### OperationsWithEmpDetails.js
Works with an array of employee objects and demonstrates inserting, deleting, and updating values in the list.

### serarchingElementInArr.js
Implements a linear search function that returns the index of a searched element or `not found`.

### sumOfAnArr.js
Calculates the sum of all numbers in an array using a loop.

## Concepts Covered
- `if/else` and comparison operators
- Array traversal with `for` loops
- Search and aggregate logic
- Basic object and array updates
- Console output for result verification

## How To Run
Use Node.js to execute any file from the terminal:

```bash
node Biggest_of_2Numbers.js
node sumOfAnArr.js
```

## Notes
- These files are beginner-level examples.
- Most scripts use hardcoded sample data so the focus stays on the logic.
- The outputs are printed in the console.
