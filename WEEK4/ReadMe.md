# WEEK 4 - Intro to Basic HTML Creations

## Overview
This week introduces basic HTML page structure and common beginner elements. The exercises focus on headings, paragraphs, lists, links, images, and simple page composition without external frameworks.

## Files

### IntroToBasicHtmlCreations/BasicWebPage.html
Builds a simple content page about Pochi the Cat. It uses headings, paragraphs, an ordered list, an unordered list, a horizontal rule, and an external image to show how a basic HTML document is structured.

### IntroToBasicHtmlCreations/CreatingBasicList.html
Demonstrates a simple HTML page with a paragraph, a heading, a hyperlink, and an unordered list of fruits. This file is focused on basic text and list markup.

### IntroToBasicHtmlCreations/CreatingNestedList.html
Shows how to create nested unordered lists. It groups items such as fruits and vegetables into parent and child list structures.

## Concepts Covered
- HTML document structure
- Headings and paragraphs
- Ordered and unordered lists
- Nested list creation
- Links and image embedding
- Basic semantic page layout

## How To View
Open any file in a browser or use a Live Server extension in VS Code.

```bash
start BasicWebPage.html
```

## Notes
- These pages are intentionally simple and beginner-friendly.
- The focus is on learning HTML tags and nesting rules.
- External image and link resources are used in `BasicWebPage.html`.
