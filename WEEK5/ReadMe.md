WEEK 5 - HTML Layouts and CSS Styling

📌 Introduction

This week focuses on building structured and visually styled webpages using HTML and CSS.
The exercises move beyond plain HTML pages and introduce layout design, responsive styling, forms, tables, navigation bars, cards, and CSS Grid concepts.

The projects in this repository demonstrate how webpages are designed and styled using:

Semantic HTML
CSS styling
Flexbox layouts
CSS Grid
Responsive design techniques

These examples help learners understand how modern webpage layouts are created and organized.

This week acts as an important step toward frontend development and UI design.

🎯 Objectives of This Week

The main objective of this repository is to understand webpage layout creation and styling using CSS.

After completing these exercises, learners will be able to:

Create structured webpages
Design responsive layouts
Build navigation bars
Create forms and tables
Use CSS Grid and Flexbox
Apply styling and spacing
Develop beginner-level UI designs
