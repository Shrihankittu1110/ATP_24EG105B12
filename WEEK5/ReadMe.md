# WEEK 5 - HTML Layouts and CSS Styling

## Overview
This week expands from plain HTML into styled page layouts. The exercises cover blog-style UI, table formatting, forms, CSS Grid, and a responsive navigation-and-cards layout.

## Files

### BasicBlogPage/inde.html
Creates a blog landing page with a top navigation bar, search form, hero text, multiple content cards, and a footer section. The file is named `inde.html` in the folder, so it should be opened with that filename.

### BasicBlogPage/style.css
Styles the blog layout with a colored hero section, card layout, navigation bar, footer, and responsive behavior for smaller screens.

### CreatingTables/index.html
Demonstrates multiple HTML table patterns, including row spans, column spans, grouped headers, result tables, and a larger user list table.

### CreatingTables/style.css
Applies shared table styling, borders, alignment, and sizing for the different table examples in the folder.

### FormCreation/index.html
Builds a form with a fieldset, legend, text fields, password input, checkbox group, radio group, select menu, textarea, and submit button.

### FormCreation/style.css
Styles the form with centered layout, full-width inputs, spacing, and a highlighted submit button.

### ImplementingGridStyle/index.html
Shows a simple grid container with five child blocks to demonstrate CSS Grid placement.

### ImplementingGridStyle/style.css
Defines the grid template, spans, colors, gaps, and responsive collapse into a single-column layout on smaller screens.

### WebPageWithNavBarANDImg/index.html
Creates a page with a top navigation bar and a row of image cards containing titles and short descriptions.

### WebPageWithNavBarANDImg/style.css
Styles the navigation, card layout, images, and responsive spacing for the page with the navbar and cards.

## Concepts Covered
- Semantic HTML structure
- Tables with `rowspan` and `colspan`
- Forms and form controls
- CSS Flexbox and CSS Grid
- Responsive design with media queries
- Card, navbar, and footer layouts

## How To Open
Open the HTML files directly in a browser or use Live Server in VS Code.

```bash
start BasicBlogPage/inde.html
```
