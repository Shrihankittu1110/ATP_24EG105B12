WEEK 4 - Intro to Basic HTML Creations 

📌 Introduction

This week introduces the fundamentals of HTML (HyperText Markup Language), which is the standard language used to create webpages.

The exercises in this repository focus on understanding how web pages are structured using basic HTML elements such as:

Headings
Paragraphs
Lists
Links
Images
Nested lists

These beginner-level examples help learners understand how content is organized and displayed inside a web browser without using external frameworks or styling libraries.

This week serves as the foundation for future frontend development concepts such as:

CSS styling
Responsive design
JavaScript DOM manipulation
Web application development

🎯 Objectives of This Week

The main objective of this repository is to understand the basic structure of HTML documents and commonly used HTML tags.

After completing these exercises, learners will be able to:

Create basic HTML pages
Use headings and paragraphs properly
Build ordered and unordered lists
Create nested lists
Add hyperlinks
Embed images into webpages
Understand semantic page structure

📘 Detailed Explanation of Files

1️⃣ BasicWebPage.html

📌 Definition

This file demonstrates how to create a complete basic HTML webpage using multiple beginner-level HTML elements.

The webpage is based on content about Pochi the Cat and demonstrates how different HTML tags work together to form a structured webpage.

🧠 Concepts Used

Concept	Definition	Why It Is Used
HTML Document Structure	Standard webpage structure	Organize webpage
Headings	Title and section labels	Define sections
Paragraphs	Blocks of text	Display content
Ordered List	Numbered list	Sequential information
Unordered List	Bullet list	General listing
Horizontal Rule (hr)	Horizontal separator line	Separate sections
Images	Display pictures	Visual content

🔍 Logic Explanation

The webpage organizes content using:

Headings for titles
Paragraphs for descriptions
Lists for grouped information
Images for visual representation

This demonstrates how a simple webpage layout is created using semantic HTML elements.

2️⃣ CreatingBasicList.html

📌 Definition

This file demonstrates basic text formatting and list creation in HTML.

It includes:

A heading
A paragraph
A hyperlink
An unordered list of fruits

🧠 Concepts Used

Concept	Definition	Why It Is Used
Paragraph Tag (p)	Displays text content	Add information
Heading Tag (h1)	Main title	Define page heading
Anchor Tag (a)	Creates hyperlinks	Navigate to webpages
Unordered List (ul)	Bullet list	Group items
List Item (li)	Individual list element	Represent entries

🔍 Logic Explanation

The webpage demonstrates how basic HTML elements can be combined to display text content and grouped lists.

It also introduces hyperlinks, which are essential for web navigation.

3️⃣ CreatingNestedList.html
📌 Definition

This file demonstrates how nested lists work in HTML.

Nested lists are lists placed inside another list item.

🧠 Concepts Used

Concept	Definition	Why It Is Used
Nested Lists	Lists inside lists	Create hierarchy
Parent List	Main category list	Group sections
Child List	Subcategory list	Organize related items
Unordered Lists	Bullet-style grouping	Structured data display

🔍 Logic Explanation

The webpage groups items into categories such as:

Fruits
Vegetables

Each category contains its own sub-list of related items.

This demonstrates hierarchical data representation using HTML lists.
